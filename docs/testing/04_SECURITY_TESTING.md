# 04 Security Testing

Security testing ověřuje Zero Trust a policy enforcement.

## Scénáře

- neplatný token,
- neznámý nebo revokovaný zdroj,
- pokus o překročení classification limitu,
- access denied podle RBAC,
- access denied podle ABAC,
- pokus o subscription mimo AOR,
- prompt injection proti AI Gateway,
- pokus o odeslání citlivých dat externímu providerovi,
- offline cache po změně device trust.
