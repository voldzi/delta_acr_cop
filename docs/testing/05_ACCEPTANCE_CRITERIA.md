# 05 Acceptance Criteria

## Dokumentační baseline

- všechny požadované adresáře a dokumenty existují,
- každý adresář má index,
- OpenAPI a JSON Schema jsou validní,
- integrační kontrakt v1 je srozumitelný pro SIM tým,
- bezpečnostní a AI omezení jsou explicitní,
- ADR jsou vytvořené.

## Budoucí MVP

- ingest single i batch eventů,
- Source Registry lifecycle,
- canonical model validace,
- COP query a subscription,
- snapshot + delta stream,
- symbol resolver,
- AI Gateway s guardrails,
- audit a observabilita,
- contract tests proti SIM payloadům.
