# ADR0037: Server-owned community observation presence

Status: accepted for the owner-authorized community reporting delivery2026-10-04.

COP owns the active-map decision. Keep the lifecycle record unchanged and expose
an additive `presence` summary; suppression by independent absence is reversible
within the observation validity. Durable storage errors cannot fall back to RAM
acknowledgements. Category `police_patrol` remains a short-lived advisory, never a
routing closure. Only explicit reviewed mapping of a real obstruction to graph
version and directed edges can affect SIM routing.

See [exact rules and integration](../integration/31_JIZDA_COMMUNITY_REPORTS.md).
