API kontrakt je baseline pro budoucí implementaci hlavního COP systému a nezávislý vývoj SIM projektu.

Aktuální pilot zahrnuje ingest, source registry, source-neutral map catalog, aktuální COP tracks, temporal track history, symbology resolve, audit a AI assistant endpointy.

`openapi/openapi.json` je autoritativní kontrakt. Tento adresář drží generovaný YAML export a doprovodná schémata kvůli kompatibilitě s původní dokumentací.
