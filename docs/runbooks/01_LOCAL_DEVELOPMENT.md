# 01 Local Development

Tento runbook je placeholder pro navazující implementační skeleton.

## Očekávaný postup

1. Nainstalovat runtime podle budoucího monorepa.
2. Spustit lokální databázi, event bus a cache přes Docker Compose.
3. Nastavit OIDC/API tokeny pro laboratorní režim.
4. Spustit `cop-api` a `cop-web`.
5. Ověřit `/health/live`, `/health/ready` a `/metrics`.

Přesné příkazy doplní implementační krok.
