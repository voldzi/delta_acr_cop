# 04 Codex Usage

Codex se používá pro vývojářskou asistenci, generování dokumentace, návrh testů, kontrolu konzistence kontraktů a práci s kódem. V běžném operačním UI není Codex rozhodovací autorita.

## Povolené použití

- generování a údržba dokumentace,
- návrh skeletonu aplikace,
- contract tests,
- refaktoring a review kódu,
- vysvětlení technických chyb,
- tvorba runbooků.

## Omezení

Codex nesmí generovat targeting workflow, navádění, weapon control ani doporučení použití síly. Prompt templates musí obsahovat bezpečnostní hranice systému.
