# 06 Accessibility and Field Usability

UI musí být použitelné na notebooku, tabletu a velkém situačním displeji.

## Požadavky

- vysoký kontrast,
- čitelné stavy a badge,
- ovladatelnost klávesnicí,
- minimální rušivé animace,
- jasný offline/degraded stav,
- stabilní layout při realtime updatech,
- zřetelná hierarchie vrstev a detailů,
- podpora dotykového ovládání pro tablet.

Barvy nesmí být jediným nositelem kritické informace.
