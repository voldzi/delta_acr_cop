# 05 Out of Scope

Mimo rozsah baseline a budoucího MVP zůstává:

- automatický výběr cílů,
- doporučování útoku nebo obrany,
- navádění prostředků,
- řízení zbraní,
- autonomní rozhodování o použití síly,
- bojová gamifikace,
- certifikované tvrzení o plné NATO interoperabilitě bez formálního ověření,
- přímé sdílení interních databází mezi COP a SIM projektem,
- produkční hardening bez samostatného security review.
