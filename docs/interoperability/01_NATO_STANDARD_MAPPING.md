# 01 NATO Standard Mapping

Interoperability baseline připravuje systém na mapování relevantních NATO standardů, ale netvrdí certifikovanou shodu.

## Principy

- standardy mapovat přes explicitní adapter a mapping katalog,
- udržovat canonical model jako interní zdroj pravdy,
- verzovat mapping matrix,
- testovat každý mapping contract testy,
- jasně označit lokální rozšíření,
- oddělit datovou sémantiku od UI prezentace.

Prioritou první fáze je APP-6/STANAG 2019 symbol rendering skeleton.
