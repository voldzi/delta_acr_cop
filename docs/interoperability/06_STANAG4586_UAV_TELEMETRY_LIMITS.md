# 06 STANAG 4586 UAV Telemetry Limits

STANAG 4586 UAV telemetry je kandidát pro budoucí UAV adapter. Baseline definuje limity, aby nedošlo k záměně situační platformy za řídicí systém.

## Limity

- COP přijímá telemetry a status jako situační data.
- COP neřídí UAV, neposílá navigační příkazy a neplánuje mise.
- Adapter převádí pozorování na canonical event envelope.
- UI zobrazuje stav a provenance, nikoli ovládací prvky prostředku.

Tento limit je bezpečnostní hranice systému.
