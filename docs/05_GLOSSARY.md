# 05 Glossary

| Termín | Význam |
| --- | --- |
| COP | Common Operating Picture, sdílený situační obraz z více zdrojů. |
| Canonical model | Interní datový model izolující core logiku od externích formátů. |
| Event envelope | Standardní obálka události s identitou zdroje, časem, klasifikací, payloadem a kvalitou. |
| Source Registry | Registr externích zdrojů, jejich oprávnění, stavu a trust profilu. |
| Provenance | Dohledatelnost původu dat a transformačních kroků. |
| Confidence | Vysvětlitelné skóre důvěry v objekt nebo pozorování. |
| Synthetic data | Data ze simulace nebo testu, striktně oddělená od reálných dat. |
| APP-6 / STANAG 2019 | NATO standardy pro společnou vojenskou symboliku. V baseline jde o architektonickou připravenost, ne certifikaci. |
| RBAC | Role-based access control. |
| ABAC | Attribute-based access control. |
| AI Gateway | Jednotná vrstva pro OpenAI, Codex, lokální LLM a mock providera. |
| Guardrails | Policy a validační pravidla omezující AI pouze na povolené asistivní use-cases. |
| Degraded mode | Režim omezené konektivity nebo kapacity s redukovanou granularitou dat. |
