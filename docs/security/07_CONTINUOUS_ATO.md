# 07 Continuous ATO

Continuous Authorization to Operate znamená průběžné risk-based posuzování změn.

## Změny vyžadující posouzení

- nový datový zdroj,
- nový AI provider,
- změna integračního kontraktu,
- změna klasifikačních pravidel,
- změna Source Registry oprávnění,
- nová edge/offline capability,
- nové interoperability mappingy.

Výstupem je aktualizovaný risk register, threat model nebo ADR podle povahy změny.
