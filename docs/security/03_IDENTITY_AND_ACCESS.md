# 03 Identity and Access

IAM baseline:

- OIDC/OAuth 2.1,
- FIDO2/WebAuthn pro privilegované role,
- krátké access tokeny,
- refresh token rotation,
- session binding na zařízení,
- step-up auth pro citlivé administrátorské akce,
- princip nejmenších oprávnění.

Uživatelé, systémoví klienti i AI administrace musí používat oddělené scope a auditní stopy.
