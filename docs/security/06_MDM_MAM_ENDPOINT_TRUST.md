# 06 MDM MAM Endpoint Trust

Mobilní a osobní zařízení vyžadují řízený endpoint trust.

## Požadavky

- chráněný pracovní profil,
- lokální šifrování cache,
- remote wipe služebních dat,
- kontrola jailbreak/root/debug stavu,
- blokace nekompliantních zařízení,
- session binding,
- omezení exportů podle device posture.

Endpoint trust je ABAC atribut a může omezit vrstvy, rozlišení dat nebo offline cache.
