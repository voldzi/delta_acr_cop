# 10 Professional Workspace UX Architecture

UX architektura staví na obecných principech profesionální situační aplikace: system-of-systems, web-first přístup, vrstvený situační obraz, realtime data, degraded provoz a continuous security.

## UI jako konzument dat

Mapové UI není zdroj pravdy. Čte policy-filtered COP state, používá civilní nebo profesionální symboliku podle režimu zobrazení a vysvětluje confidence, provenance, stáří dat a konflikty zdrojů.

## Hlavní UI oblasti

- top status bar,
- left layer panel,
- central map canvas,
- right object detail panel,
- bottom timeline/replay panel,
- AI assistant drawer.

Žádná UI oblast nesmí zavádět targeting, navádění, weapon workflow ani doporučování použití síly.
