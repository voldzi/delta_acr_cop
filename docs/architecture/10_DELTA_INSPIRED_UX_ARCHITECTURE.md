# 10 DELTA Inspired UX Architecture

UX architektura se inspiruje veřejně popsanými principy DELTA pouze obecně: system-of-systems, web-first přístup, vrstvený situační obraz, realtime data, degraded provoz a continuous security.

## UI jako konzument dat

Mapové UI není zdroj pravdy. Čte policy-filtered COP state, zobrazuje symboly přes NATO renderer a vysvětluje confidence, provenance, stáří dat a konflikty zdrojů.

## Hlavní UI oblasti

- top status bar,
- left layer panel,
- central map canvas,
- right object detail panel,
- bottom timeline/replay panel,
- AI assistant drawer.

Žádná UI oblast nesmí zavádět targeting, navádění, weapon workflow ani doporučování použití síly.
